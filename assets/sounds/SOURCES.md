# Notification sounds

The five bundled WAV clips come from [Mildly Useless](https://mildlyuseless.com/res/), which publishes them under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Reduced levels make them suitable for notifications.

| File | Original sound |
| --- | --- |
| boing.wav | [Cartoon Boing](https://mildlyuseless.com/res/sfx/cartoon/cartoon-boing.wav) |
| squeak.wav | [Rubber Squeak](https://mildlyuseless.com/res/sfx/cartoon/cartoon-squeak-toy.wav) |
| whistle.wav | [Slide Whistle Down](https://mildlyuseless.com/res/sfx/cartoon/cartoon-slide-whistle.wav) |
| pop.wav | [Cartoon Pop Burst](https://mildlyuseless.com/res/sfx/cartoon/cartoon-pop-burst.wav) |
| scratch.wav | [Record Scratch](https://mildlyuseless.com/res/sfx/cartoon/cartoon-record-scratch.wav) |

The ICQ preset uses the owner's local icq-message.wav file, with the Windows notification sound as fallback.
